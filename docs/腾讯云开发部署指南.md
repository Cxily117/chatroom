# 星火聊天室 · 腾讯云开发部署指南（拿域名给老师检查）

这套代码是**纯静态网页**，可以直接放到腾讯云开发的「静态网站托管」，系统会免费分配一个域名。老师用浏览器打开网址、输入账号密码就能用，**不用装任何软件、不用双击启动脚本**。

> 提供免费额度：存储 1GB/月、CDN 流量 5GB/月、HTTPS 证书免费，课堂演示完全够用。

---

## 完整步骤（照着点即可）

### 第 1 步：开通云开发环境
1. 打开 <https://console.cloud.tencent.com/tcb/env/index>
2. 点「新建环境」，名称随便填（如 `chatroom`），付费模式选**按量计费（0 元起）**
3. 点「立即开通」，等约 1 分钟初始化完成

### 第 2 步：开启匿名登录（云 SDK 初始化需要，不影响账号登录）
1. 进入你的环境 → 左侧「身份认证」→「登录方式」
2. 打开**匿名登录**的开关
3. （账号登录由页面内置：登录页「立即注册」创建账号、密码哈希存储，与匿名登录互不冲突）

### 第 3 步：建数据库集合
1. 左侧「数据库」→ 点「新建集合」，名称填：`chat_messages`
2. 权限设为「**所有用户可读，仅创建者可写**」
   - 说明：本项目同一浏览器用同一身份；如需多人互相看到消息，设为「所有用户可读写」即可
3. 不用手动建字段，写入消息时会自动生成

### 第 4 步：把环境 ID 填进代码
1. 在环境总览页复制你的**环境 ID**（形如 `chatroom-1g8abcd1234`）
2. 用记事本打开本项目 `index.html`，找到最上面的配置段：

   ```js
   window.CHAT_CONFIG = {
     env: '',   // ← 把引号里改成你的环境 ID
     ...
   };
   ```
   改成：
   ```js
   env: 'chatroom-1g8abcd1234',
   ```
3. 保存。填了 env 后，网页会自动从「本地存储模式」切换成「腾讯云数据库模式」，页面底部会显示当前模式。

### 第 5 步：上传到静态网站托管
两种方式任选：

**方式 A：控制台手动上传（最简单）**
1. 打开 <https://console.cloud.tencent.com/tcb/hosting>，选中你的环境，点「开始使用」初始化（约 3 分钟）
2. 初始化完成后，点「上传文件」，把本项目的 `index.html` 传上去（根目录）
3. 完成后会显示一个默认域名，形如：
   `https://chatroom-1g8abcd1234-1300000000.tcloudbaseapp.com`

**方式 B：命令行上传（会 Git 的话）**
```bash
npm install -g @cloudbase/cli
tcb login
tcb hosting deploy ./index.html /index.html -e 你的环境ID
```

### 第 6 步：把域名发给老师
把第 5 步拿到的 `https://....app.tcloudbase.com` 链接发给老师。老师打开 → 点「立即注册」创建账号（或已有账号直接登录）→ 进入群聊，就能看到完整的群聊、图片/文件/语音、加好友私聊、AI 问答（@小星）、隔离、限流、数据库视图。

> **跨设备加好友**：让两台设备（电脑 + 手机）都打开这个网址、各自注册账号，等 2~3 秒后就能在「👥 好友 → 🔍 找人」里互相搜到、发申请、同意、私聊。消息、账号目录、好友关系都存在同一个 `chat_messages` 集合，不需要新建集合或加后端。右上角徽章显示「☁ 云端数据库」即表示已连云端。

> 发布到正式 HTTPS 域名后，浏览器才会正常授权麦克风，「🎤 语音」可直接录音；在预览面板里点它会提示改用「上传音频文件」降级演示。

## 双模式说明（重要）

| 情况 | 运行模式 | 数据存在哪 | 适用 |
|---|---|---|---|
| `env` 留空 | 本地存储（徽章「💾 本地存储」） | 浏览器 localStorage | 预览面板、直接双击打开、本地调试 |
| `env` 已填 + 已开匿名登录 | 云数据库（徽章「☁ 云端数据库」） | 腾讯云 `chat_messages` 集合：消息 + 账号目录 + 好友关系 + 私聊 | 发布上线，多设备共享数据、可跨设备加好友 |
| **`apiBase` 已填 + 后端服务在线** | **自建后端（徽章「🌐 后端 API」）** | 后端 `server/` 写入云数据库，账号与归属由服务端校验 | 作业要求「有独立后端」时用，见 `docs/云托管部署指南.md` |

这样设计的好处：**你在任何环境都能看到完整界面并点击体验**，不会因为没配云端就"点不了"；发布时只需改一行 env。

> 本地模式下账号表和好友关系只在本机，「找人」只能搜到本机注册过的账号（用「注册 A → 退出 → 注册 B」切换演示）。发布到云端后这两类数据自动上云，才能真跨设备。

## 常见问题

- **页面显示"本地存储模式"**：说明 `env` 还没填，或填错了。检查 `index.html` 顶部配置。
- **想加独立后端**：静态托管只发前端，不会跑 `server/`。后端要单独在云托管建服务（目录填 `server`、端口 80），再把域名填进 `apiBase`，详见 `docs/云托管部署指南.md`。
- **AI 没反应**：`@小星` 触发的扣子云函数未配置或调用失败时，会自动降级成本地 8 条规则助手，断网也能演示。配置方法见 `docs/扣子智能体接入指南.md`。
- **录音提示"无法录音"**：预览面板不给麦克风权限，按提示选「确定」上传 mp3/wav 即可作为语音消息；发布到正式域名后可直接录音。
- **上传文件报"超过上限"**：本地演示建议 <500KB；浏览器存储受限时 <180KB。云端模式可在 `CHAT_CONFIG.maxFileBytes` 放宽。
- **换设备看不到之前的消息 / 搜不到另一台设备注册的账号**：说明当前是本地模式（`env` 留空或云端初始化失败）。填好 `env`、上传到静态托管后，两台设备打开**同一个网址**且徽章都显示「☁ 云端数据库」，消息、账号目录、好友关系就都共享了。新账号/新申请约 2~3 秒同步一次，点一下侧栏切视图可立即刷新。
- **数据库权限报错**：回到第 3 步，把集合权限设为「所有用户可读写」（课堂演示用）。
- **域名打不开**：CDN 首次部署有几分钟缓存，稍等刷新；确认文件传到了根目录。

## 给老师讲解的要点

1. **前端**：单文件 `index.html`，原生 HTML/CSS/JS，样式内嵌，无需构建。
2. **后端**：腾讯云开发的后端服务（静态托管 + 云数据库 + 匿名登录 + 云函数），免运维。
3. **数据库**：云数据库集合 `chat_messages`，每条消息带 `ownerId`、`kind`、`createdAt`；附件消息额外带 `image` / `file` / `audio`，私聊消息带 `dm` / `toUid`。同一集合还存 `kind=profile`（账号目录）与 `kind=social`（好友关系事件流），因此**不需要新建集合**就能跨设备加好友；页面内「🗄 数据库」视图可直接看字段。
4. **多媒体与社交**：图片/文件/语音都用 base64 随消息传输，文件可下载、语音可播放；好友申请 → 同意 → 私聊，私聊靠 `dm` 字段在群聊大厅严格过滤。云端模式下好友关系用 append-only 事件流同步，两台设备并发操作不会互相覆盖。
5. **安全**：owner_id 归属隔离（「个人」视图 + 只能删自己的）、私聊过滤、滑动窗口限流（60 秒 8 条）、`esc()` 输出转义、附件只信任 `data:` 前缀。
6. **智能体**：消息带 `@小星` 触发扣子编程云函数（真大模型 + 对话记忆）；未配置时降级本地规则助手，离线也能演示。配置见 `docs/扣子智能体接入指南.md`。
