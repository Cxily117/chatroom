# 小星智能体：免费 AI 接入指南

## 背景

原方案用扣子（Coze）智能体做 AI 答疑，但扣子个人免费版的**积分耗尽后应用会停止服务**（HTTP 402「此应用已停止服务」），此时小星会自动降级为内置规则回答。

为不依赖扣子积分，本项目在**服务端新增了一个兼容 OpenAI 格式的免费 AI 代理接口** `/api/ai`，可接入任意免费大模型。密钥只存在服务端环境变量，不会下发到浏览器。

## 两层自动降级（前端已实现）

1. **优先**请求同源 `/api/ai`（云托管后端）—— 配置了免费大模型 Key 即可用
2. 失败则请求原扣子云函数 `aiProxy` —— 扣子恢复服务后自动生效
3. 再失败则用**内置规则**回答（项目架构、数据库、限流、部署、计网知识点等常见问题都有答案）

也就是说：**什么都不配也能演示**（走规则），**配一个免费 Key 就有真 AI**。

## 免费大模型推荐（2026 年）

| 平台 | 免费模型 | 免费额度 | 注册地址 | 接口地址（AI_BASE_URL） |
|---|---|---|---|---|
| **智谱 AI（推荐）** | `glm-4-flash` | 永久免费、无限量、128K 上下文 | open.bigmodel.cn | `https://open.bigmodel.cn/api/paas/v4` |
| 硅基流动 | `Qwen/Qwen2.5-7B-Instruct` 等 | 多个小模型永久免费 | cloud.siliconflow.cn | `https://api.siliconflow.cn/v1` |
| 百度千帆 | `ERNIE-Speed` | 永久免费 | console.bce.baidu.com/qianfan | 按控制台文档 |

## 接入步骤（以智谱为例，约 5 分钟）

1. 打开 `open.bigmodel.cn`，手机号注册登录 → 控制台「API Key」→ 复制 Key
2. 云开发控制台 → 云托管 → `chatroom` 服务 → 服务配置 → 环境变量，新增两条：
   - `AI_API_KEY` = 刚才复制的 Key
   - （可选）`AI_MODEL` = `glm-4-flash`；`AI_BASE_URL` 默认智谱，一般不用填
3. 点「更新服务」重新部署
4. 打开网站，`@小星` 问一句「这个项目是什么架构」——能回答且每次不一样，说明真 AI 已接通

接口自测：

```bash
curl -X POST https://<你的域名>/api/ai \
  -H "Content-Type: application/json" \
  -d '{"question":"这个项目是什么架构？","history":[]}'
# 预期：{"ok":true,"answer":"..."}
```

## 为什么密钥放后端不放前端

前端是所有人都能打开的静态文件，密钥写在里面任何人查看源码就能盗用。放在服务端环境变量里，浏览器只把问题发给 `/api/ai`，由后端带密钥调用大模型——这是标准的密钥保护做法，也是答辩可讲的加分点。

## 恢复原扣子智能体（可选）

如果要让陈思媛的扣子智能体重新工作，需要其扣子账号**完成每日登录领取积分或充值**（个人版积分归零会停服）。配置不变，云函数会自动恢复调用；前端已做双通道，恢复后无需改代码。
