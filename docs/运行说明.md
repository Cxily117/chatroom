# 运行说明（腾讯云网站托管版）

本项目主程序只有一个 `index.html`（单文件，内嵌全部 CSS/JS），另附 `cloudfunctions/aiProxy/`（扣子智能体云函数，可选）与 `docs/`（说明文档）。两种运行方式：

## 方式 A：本地直接看（零配置）

双击 `index.html`，或在浏览器打开它（也可以直接在预览面板里操作）。此时是**本地存储模式**，先点「立即注册」创建账号，或已有账号直接登录。群聊、图片/文件/语音、加好友私聊、隔离、限流、AI 全部可完整演示，数据存在当前浏览器里。

- 不需要 Python、不需要装数据库、不需要联网（AI 的云端部分不可用会自动降级为本地规则助手）。
- 页面底部显示当前存储介质；预览面板常禁用 `localStorage`，程序会自动降级到 `sessionStorage / Cookie / window.name / 内存`，尽量保证刷新不丢数据。
- 本地模式下**账号表和好友关系只在这台设备上**，所以「找人」只能搜到本机注册过的账号。想演示加好友，用「注册 A → 退出 → 注册 B」切换账号即可（见下方演示顺序）。
- 想清空演示数据：浏览器 F12 → Application → Local Storage → 删掉 `spark_chat_` 开头的键；或点侧栏「退出」换个账号。

## 方式 B：发布上线拿域名（推荐给老师检查，也是跨设备的前提）

按 `docs/腾讯云开发部署指南.md` 操作，六步：
1. 开通云开发环境（按量计费，有免费额度）
2. 开启匿名登录
3. 建 `chat_messages` 集合并设权限
4. 把环境 ID 填进 `index.html` 顶部 `env`
5. 上传 `index.html` 到静态网站托管
6. 把分配的 `https://....app.tcloudbase.com` 域名发给老师

此时是**云数据库模式**（右上角徽章变成「☁ 云端数据库」）。**消息、账号目录、好友关系、私聊全部存进同一个 `chat_messages` 集合**，两台设备打开同一个网址即可互相发现、加好友、私聊。不需要新建集合、不需要额外后端。智能体接扣子见 `docs/扣子智能体接入指南.md`。

> 云端模式靠 2.5 秒轮询同步，另一台设备注册/发申请后，等 2~3 秒（或点一下侧栏切视图）就会刷新出来。

## 界面与主题

- **亮 / 暗主题**：登录页右上角、聊天页右上角各有一个圆形切换按钮。首次打开跟随系统配色（`prefers-color-scheme`），手动切换后会记住选择，刷新不丢；手机、平板同样适配。
- **统一图标**：侧栏与工具栏改用一套 SVG 线性图标，替代原来的 emoji。
- **动效**：新消息逐条淡入、切换视图有过渡、发送按钮有轻反馈、按钮点击有涟漪、小星回复时显示「正在输入」三点动画；系统开启「减少动态效果」时自动关闭动画。
- **气泡精修**：按昵称生成稳定的头像配色、时间分组分割线、同一人连续消息合并、气泡小尾巴、悬停浮出删除按钮。
- **个性装扮 · 13 套气泡（用户自选）**：点聊天页右上角的调色板按钮，会打开商城式三列缩略图网格，分「经典皮肤」5 套（经典圆润 / 简约扁平 / 玻璃拟态 / 渐变霓虹 / 手账便签）与「萌系装扮」8 套（拟态小猫 / 粉白兔 / 尖叫鸡 / 水豚噜噜 / 心室信封 / 电子显示器 / 十字蓝天使 / 丝带蜜语）。多数萌系是**带猫耳、兔耳、蝴蝶结、尾巴、显示器底座的卡通造型气泡**；**「十字蓝天使」用参考原图抠出的透明 PNG 整层贴入**（翅膀 / 十字 / 星星 / 心形，都是原图素材）；**「心室信封」改用 SVG 矢量重画**（粉色双线藤蔓边框用 9 宫格拉伸保持清晰、长消息不发虚；右下角两层信封 + 红爱心封蜡 + 红线、四角黄星 / 橙块 / 蓝箭头都是固定尺寸 SVG，不会被拉变形；气泡内部透明、没有白底块），缩略图同源；**「水豚噜噜」按原版装扮重做：奶油色气泡 + 左上橘子 + 右上黄格子胶带 + 左下两颗星星 + 右下前方独立的小水豚**——水豚本体是**直接从原版参考图抠出的透明 PNG**（内嵌 base64，保持单文件），不是手绘图标，3D 质感与原图一致；显示尺寸约 46px，缩略图同源，文字区留出右侧空间不被角色挡住。由 CSS 变量 + 装饰元素绘制，亮 / 暗主题都适配。选择保存在本机（`spark_chat_bubble_v1`），刷新不丢，纯展示、不影响消息数据。
- **悬浮智能体「小星」**：聊天区右下角悬浮一个 **3D 奶油黄小羊角色**（卷发 + 粉色笑脸 + 翅膀 + 星星魔法棒），形象是**直接从参考原图抠出的透明 PNG**（内嵌 base64，保持单文件），不是手绘图标；显示约 104×128px，不遮挡聊天。**按住可拖动**、**点一下换一个标签动作**（打招呼 → 思考中 → 开心 → 撒娇 → 答疑，循环），因为是整张图片，动作改用整体摇摆 / 歪头 / 跳动 / 缩身 / 漂浮动画 + 闪光表现，并弹出一句台词。右上角 × 可收起，收起后右下角出现「✦ 小星」唤回；下面「@ 问小星」按钮会自动在输入框填好 `@小星`，直接写问题发送即可调用智能体。
- **表情包**：工具栏「表情」按钮打开面板，含 41 个 Emoji 与 8 张内置 SVG 萌宠表情包（猫猫探头 / 粉白兔 / 尖叫鸡 / 抱抱熊 / 熊猫呆呆 / 青蛙噗噗 / 小星本星 / 晚安月）。Emoji 点一下插入输入框（可配合文字发送），表情包点一下直接发成一个大贴纸消息；数据库视图 attachment 列会记录 `sticker/xxx`。
- **提示与确认**：全部改为页面内 Toast / 确认框，不再用浏览器原生弹窗（预览面板不会被弹窗阻塞）。
- **空状态与骨架屏**：没有消息时显示插画，云端拉取期间显示骨架占位。
- 往上翻历史时，2.5 秒的自动刷新不会把视线强行拉回底部。

## 功能与演示顺序

1. **注册/登录**：新用户点「立即注册」→ 账号、密码（≥4 位）、确认密码、昵称（选填）→「注册并进入」。已有账号在登录页输入账号密码进入。
2. **群聊**：输入后按 Enter（Shift+Enter 换行）。中文输入法选完字后再按 Enter 才发送。
3. **发图片**：点工具栏「图片」，自动压缩后发出，点缩略图可看大图（带缩放动画）。
4. **上传文件**：点「文件」，选择任意文件 → 消息里生成文件卡片，点「下载」可保存。本地演示建议 <500KB；浏览器存储受限时 <180KB。
5. **语音聊天**：点「语音」开始录音，再点一次「停止」即发出语音条，点播放按钮可收听并显示时长（最长 60 秒）。**预览面板/无麦克风权限时会弹出自定义确认框，提示改用「选择音频文件」**，上传 mp3/wav 也能作为语音消息演示，任何环境都不卡壳。
6. **发表情包**：点工具栏「表情」→「Emoji」点任意表情会插进输入框（可以混着文字发）；切到「萌宠表情包」，点一张贴纸就直接发出一个大贴纸消息。表情包同样受 60 秒 8 条限流，也会出现在「数据库」的 attachment 列（`sticker/xxx`）。
7. **逗悬浮小星**：聊天区右下角的小星整体形象保持原图不变，点一下会换一种动作 + 粒子特效（比心 → 打招呼 → 思考中 → 开心 → 撒娇 → 答疑 → 打盹 → 惊喜），还会每 6.5 秒自己安静换一个动作（自动换不弹台词）；按住可以拖到任意位置，收起后右下角可唤回。点「@ 问小星」会自动填好触发词，写完问题发送就会调用智能体。
8. **加好友与私聊**：点侧栏「好友」→「找人」搜索账号 →「加好友」→ 对方在「申请」里同意 → 好友列表点「私聊」进入两人对话。私聊消息带 `toUid`，**群聊大厅严格过滤，不会串消息**；切走后侧栏「私聊」可一键返回。
   - **本机演示闭环**（方式 A）：注册 A → 退出 → 注册 B → B 搜 A 发申请 → 退出用 A 登录 → 同意 → 双方互发私聊。
   - **真·跨设备闭环**（方式 B）：手机/电脑 A 注册账号 A，另一台设备 B 打开同一网址注册账号 B → B 在「找人」搜到 A 发申请 → A 在「申请」里同意 → 两台设备互发私聊。约 2~3 秒同步一次。
9. **个人视图**：侧栏「个人」，按 owner_id 过滤，只看自己的消息。
10. **智能助手**：消息里带 `@小星` 发出，或写好后点侧栏「小星」，小星（扣子）会接话，带最近对话记忆；等待期间消息区显示「正在输入」动画。
11. **看数据库（三张表）**：侧栏「数据库」，顶部可切换 ① 消息表（mid / owner_id / owner_name / kind / content / attachment / scope / created_at）② 账号表（注册/登录的账号、昵称、**遮罩后的密码哈希**、来源、注册时间）③ 好友关系表（申请与好友关系）。账号密码**不在消息表里**，是独立的一张账号表；云端集合里还有 `kind=profile / social` 两类辅助记录，不会显示成聊天消息。
12. **删除**：鼠标移到自己的消息上会浮出「删除」按钮（触屏常显），别人的没有；删除前用自定义确认框二次确认。
13. **退出**：侧栏底部「退出」。

## 常见问题

**Q：为什么预览面板里"注册了又说没账号"？**
A：预览面板禁用浏览器持久化存储时，旧版只把账号放内存，页面一重载就清空。新版按 `localStorage → sessionStorage → Cookie → window.name → 内存` 依次降级，`window.name` 在同一标签页刷新后仍保留，账号不会丢。若换了标签页或清了缓存，本地数据仍会重置——发布到云端后不存在这个问题。

**Q：语音点了没反应 / 提示无法录音？**
A：预览面板通常不给麦克风权限。按弹窗提示选「确定」，会打开音频文件选择框，选一个 mp3/wav 就会作为语音消息发出。发布到正式 HTTPS 域名后，浏览器会正常请求麦克风权限，即可直接录音。

**Q：填了 env 但显示「💾 本地存储」？**
A：检查 env 是否完整、是否已开启匿名登录、云 SDK 能否加载（需联网）。云端初始化失败会自动降级本地模式，保证页面始终可用。右上角徽章显示当前模式：「💾 本地存储」= 数据只在本机；「☁ 云端数据库」= 已连云端。

**Q：换设备看不到之前的消息 / 搜不到另一台设备注册的账号？**
A：这是**本地模式**（徽章为「💾 本地存储」）的正常现象——账号表、好友关系、消息都存在各自浏览器里，两台设备互不相通。按方式 B 发布上线、填好 `env` 后，三者都会进云端 `chat_messages` 集合，两台设备打开同一网址即可共享、互相加好友。若已发布但仍搜不到，确认两台设备打开的是**同一个网址**、且都显示「☁ 云端数据库」。

**Q：智能体怎么接真大模型？**
A：已接扣子编程（云函数 `aiProxy` → `async_run`）。配置方法见 `docs/扣子智能体接入指南.md`。未配置或调用失败时自动降级成本地 8 条规则助手，离线也能演示。

**Q：「数据库」里显示的是哪张表？登录/注册的账号密码有数据库吗？**
A：默认看到的 ① **消息表**只存聊天消息（群聊/私聊/图片/文件/语音/AI/系统公告），不是账号库。账号密码存在**独立的账号表**：本地模式是浏览器键 `spark_chat_users_v1`，云端模式是同一集合里 `kind=profile` 的账号目录；密码只存哈希、不存明文。点「数据库」顶部的「② 账号表（登录/注册）」就能直接看到注册的账号、昵称、遮罩后的哈希和注册时间；「③ 好友关系表」看申请与好友关系。老师检查时这三张表一起看最清楚。

**Q：老师检查要看真实数据库？**
A：页面内「🗄 数据库」视图可直接看字段；发布后也可在腾讯云控制台 → 数据库 → `chat_messages` 集合里看真实记录（含 `file`/`audio`/`dm`/`toUid`，以及账号目录 `kind=profile`、好友关系 `kind=social`）。
